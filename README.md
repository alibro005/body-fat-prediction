# Body Fat Prediction

A machine learning web application that predicts **body fat percentage** based on body measurements. The project uses a trained regression model served with FastAPI and a responsive HTML, CSS, and JavaScript frontend.

## Live Demo

* **Frontend:** https://body-fat-prediction.vercel.app
* **API:** https://body-fat-prediction-api.fastapicloud.dev

## Features

* Predict body fat percentage from user inputs
* FastAPI REST API
* Responsive frontend
* Scikit-learn regression model
* Data preprocessing pipeline

## Tech Stack

* Python
* FastAPI
* Scikit-learn
* Pandas
* NumPy
* Joblib
* HTML, CSS, JavaScript
